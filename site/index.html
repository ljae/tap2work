01 / CEO에게 묻고 싶은 것

더 편한 하루를 위해, 무엇부터 바꿀까요?

앱을 보며 개발 방향을 정하고, 필요한 기능과 불편한 부분을 함께 기록합니다.

현재 합의한 제품 방향

팀의 일과 재료가
하나의 흐름으로.

직원·공유 업무·재고·발주·매장 지도를 한곳에서 연결합니다. 신입은 첫 출근 가이드에서 연습하고 버디와 함께 근무를 시작합니다.

오늘의 구현은 샘플 매장 데모입니다. 아래 질문에 의견을 주시면 실제 업무에 필요한 순서로 다음 개발을 검토할 수 있습니다.

방향 질문 · 기능 요청 남기기 ↗
01

가장 먼저 편해져야 할 일은 무엇인가요?

사장님, 버디, 직원 중 누가 어떤 순간에 어려움을 겪나요? 반복 확인이나 입력이 많은 실제 상황을 알려 주세요.

02

어떤 기능을 추가하거나 바꾸면 좋을까요?

지금의 작업 방식과 원하는 방식을 비교해 주세요. 해당 메뉴, 필요한 정보, 다음 행동을 구체적으로 적어 주세요.

03

개선됐다고 판단할 기준은 무엇인가요?

빠뜨리는 업무, 중복 확인, 설명 시간, 입력 부담 중 무엇이 줄어들어야 하나요? 실제 매장에서 확인할 기준을 함께 정해요.

02 / 현재 위치

만든 것과, 앞으로 만들 것.

저장소의 결정 기록을 기준으로 표시합니다. 완료는 각 항목에 적힌 구현 범위를 뜻합니다.

개발 단계를 불러오는 중…

Flutter 앱으로 직접 살펴보세요.

다섯 메뉴와 역할별 샘플 화면, 공급처별 발주함을 볼 수 있어요. 공개 미리보기는 고정 샘플이며 운영 기록을 저장하지 않습니다. 첫 출근 연습은 이 브라우저에만 남습니다.
