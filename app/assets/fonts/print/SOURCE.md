# PDF fonts

Loaded when generating a PDF or editing Chinese/Japanese translations; the PDF embeds the used glyphs. No manual content is sent to font providers.

- Tap2workPrint-Regular.ttf: renamed static weight 400 instance (Tap2workPrint family/PostScript names) of the existing ../PretendardVariable.ttf. License: ../PRETENDARD-OFL.txt.
- NotoSansSC-Regular.ttf: static weight 400 instance of https://github.com/google/fonts/blob/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf . SIL OFL in NotoSansSC-OFL.txt.
- NotoSansJP-Regular.ttf: static weight 400 instance of https://github.com/google/fonts/blob/main/ofl/notosansjp/NotoSansJP%5Bwght%5D.ttf . SIL OFL in NotoSansJP-OFL.txt.

Fetched 2026-10-05. Generated using fontTools.varLib.instancer.instantiateVariableFont(font, {'wght': 400}). Application typography remains Pretendard.
