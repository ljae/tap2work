# Pretendard

Runtime font: unmodified `PretendardVariable.ttf`, official v1.3.9.
Source: https://github.com/orioncactus/pretendard/blob/v1.3.9/packages/pretendard/dist/public/variable/PretendardVariable.ttf
License: PRETENDARD-OFL.txt. All glyphs and the full variable weight axis retained.

One variable face replaces four separately downloaded static faces. The original static files remain as reference sources but are no longer bundled. This reduces gzip transfer from approximately 4.24 MB to 2.95 MB; raw TTF size alone is not a network transfer measurement.
