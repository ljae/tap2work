무엇을 바꿀 수 있나요?

  1. 매뉴얼 내용과 사진
    앱의 연필 버튼에서 설명·완료 기준·팁을 수정하고 실제 매장 사진으로 교체하세요. 변경한 사본과 기존 업무 기록은 별개입니다.
  2. 모션 문구·순서·시간·색상
    웹 수정 도구에서 바꾼 뒤 ‘수정본 링크 복사’를 눌러 앱의 영상 링크에 붙여 넣고 저장하세요. JSON 원본과 영상 파일도 받을 수 있어요.
  3. 원본 재사용
    EPUB 교재, 사진 원본, 원본 영상과 모션 소스가 함께 있습니다. 자료마다 표시된 저자·라이선스·수정 이력을 보존하세요.
