TAP Work 개인정보처리방침

1. 운영자와 문의

OpenEdu는 TAP Work의 계정과 매장 운영 기능에 필요한 개인정보를 처리합니다. 개인정보 문의, 열람·정정·삭제·처리정지 요청은 esther.runstrict@gmail.com으로 보내 주세요. 계정 삭제는 앱의 내 계정에서도 직접 시작할 수 있습니다.

2. 처리 항목과 목적

로그인: Apple 또는 Google이 제공하는 계정 식별자, 이메일(Apple의 가려진 이메일 포함), 제공되는 프로필 이름·이미지와 인증 세션을 계정 식별, 로그인 유지, 본인 확인에 사용합니다. Apple·Google 비밀번호는 TAP Work가 수집하지 않습니다.

매장 운영: 사용자가 입력한 매장 정보, 크루 이름·연락처·역할·고용정보, 근무표·출퇴근·급여 예상값, 업무 완료자·시각, 매뉴얼·재고·발주 기록을 매장 협업과 기능 제공에 사용합니다. 매장 구성원의 직책에 따라 열람·수정 범위를 제한합니다.

서비스 접속 과정에서 IP 주소·요청 시각·오류와 접속 기록이 클라우드 제공자의 보안·장애 대응 로그에 남을 수 있습니다. 현재 앱은 광고 추적 SDK나 실제 GPS·Wi-Fi 출퇴근 감지를 사용하지 않습니다.

3. 저장 기간과 삭제

계정과 연결된 개인정보는 계정 이용 기간 동안 보관하며, 계정 삭제가 완료되면 운영 데이터베이스에서 로그인 계정·인증 세션·소속과 개인 식별 정보를 삭제합니다. 계정과 연결된 크루 프로필 및 개인 근무·출퇴근·급여 기록도 삭제합니다.

공유 업무·매뉴얼 등 다른 구성원과 함께 작성한 운영 내용은 작성자·완료자의 개인 식별 정보를 제거한 뒤 남을 수 있습니다. 자유 입력란이나 다른 사람이 별도로 입력한 개인정보는 계정과 자동 연결되지 않을 수 있으므로 문의 주소로 추가 삭제를 요청해 주세요.

유일한 사장님이 삭제하는 경우 별도 최종 확인 후 매장과 그 매장의 모든 운영 데이터, 모든 크루의 해당 매장 접근을 함께 삭제합니다. 다른 크루의 Apple·Google 계정이나 TAP Work 로그인 계정 자체는 삭제하지 않습니다. 사장님이 여러 명이면 남은 사장님이 매장을 계속 관리합니다.

기기 내 해당 계정의 체크리스트 백업 캐시는 삭제합니다. 사용자가 직접 내보낸 PDF·JSON 파일과 다른 기기에 저장한 사본은 직접 삭제해야 합니다. 현재 확인한 서버에는 관리형 데이터베이스 백업·시점 복구가 설정되어 있지 않습니다. 제공자의 보안 로그 보관은 제공자 계약과 설정에 따르며 운영 데이터베이스의 삭제와 시점이 다를 수 있습니다.

4. 위탁과 국외 처리

클라우드 인증·데이터 저장은 Supabase Pte. Ltd.에 위탁합니다. 현재 데이터베이스 저장 리전은 일본 도쿄(ap-northeast-1)입니다. 로그인·저장 시 계정 식별자·이메일·매장 운영 입력값이 암호화된 통신으로 전송되며 계정과 서비스 제공에 필요한 기간 동안 처리됩니다. Supabase의 지원·서비스 하위 처리자는 공급자의 데이터 처리 계약에 따릅니다. 문의: privacy@supabase.com.

Apple·Google 로그인 과정에서는 선택한 제공자가 자신의 개인정보처리방침에 따라 인증 정보를 처리합니다. 로그인은 사용자가 해당 제공자 버튼을 선택한 경우에만 시작합니다. 국외 처리에 관한 문의나 중단·삭제 요청은 OpenEdu 문의 주소로 접수할 수 있으며, 서버 저장에 필요한 처리를 원하지 않는 경우 계정 기반 매장 기능 이용이 제한될 수 있습니다.

개인정보를 광고 목적으로 판매하지 않습니다. 매장 운영자는 자신이 입력하는 크루 정보에 대해 필요한 고지·권한과 보관 의무를 확인해야 합니다. TAP Work의 예상 급여 기능을 법정 보관 기록의 유일한 저장소로 사용하지 마세요.

5. 이용자의 권리와 보호

앱의 계정 메뉴 또는 문의 이메일로 개인정보 열람·정정·삭제·처리정지를 요청할 수 있습니다. 요청 처리 시 필요한 범위에서 본인 확인을 진행합니다. 이메일 요청에 비밀번호나 Apple·Google 인증 코드를 적지 마세요.

서버는 인증된 계정과 매장 소속·직책을 확인하고, 원본 매장 데이터는 서버 전용 권한으로 접근합니다. 삭제 요청은 현재 로그인한 본인에게만 적용하며, 매장 정보가 변경되면 삭제 범위를 다시 확인합니다.

만 14세 미만의 계정 등록을 대상으로 하지 않습니다. 해당 정보가 등록된 사실을 확인하면 문의 채널을 통해 삭제를 처리합니다.

6. Apple 연결과 구독

Apple 로그인 계정 삭제 시 Apple 본인 확인과 연결 해제를 진행합니다. 계정 삭제는 Apple·Google 계정 자체의 삭제가 아닙니다. 향후 Apple 구독을 이용하는 경우 TAP Work 계정 삭제와 구독 취소는 별도이므로 Apple 구독 관리에서도 취소해 주세요. 현재 TAP Work에는 유료 구독 결제가 연결되어 있지 않습니다.

처리 항목·목적·제공자 또는 보관 정책이 바뀌면 이 페이지와 앱의 개인정보처리방침을 갱신하고 중요한 변경을 안내합니다. 이 문서의 시행일과 버전을 함께 표시합니다.
