# 번역 AI 추가 검토와 배포

사용자는 실제 원어민 검수 대신 **AI 추가 검토 후 초안 상태 배포**를 선택했다. 사람에 의한 원어민 검수는 수행하지 않았으며 번역의 `ai-draft` 상태를 유지한다.

## 최종 반영

- 고정 UI1,765행, 7개 외국어 사전 번역 각1,357개 원문.
- AI 검토에서 초기106개 원문 행의 외국어 표현435곳을 보정했다. 시간대/근무표/크루/입고/반려/수량·교대 용어, 태국어의 잔여 영어 문장, 안전 문구의 작업자·식품·주문 대상 표현을 교정했다.
- 실제 공개 웹에서 남은 업무 보드 보조 문구를 찾아 전체 업무·담당 후보/미배정/공동 업무·슬롯 표시를 번역했다. 운영 준비의 매뉴얼 검토/반영 확인/내일 준비도 문맥을 명확히 했다. 매장 작성 이름·원문, 실제 slot·state·업무 ID는 보존했다.

iOS/Android 최종 바이너리의 번역 자산7개는 검토한 소스와 byte 일치한다. iOS/Android AOT 바이너리에서 필요한 기존 공개 Supabase/Google 로그인 설정 포함을 확인했다. iOS Google 콜백 스킴도 확인했다. 웹 CI와 native 최종 빌드는 같은 보완 소스를 사용한다. Apple 심사 승인 또는 일반 공개 Android 출시를 완료했다고 보고하지 않는다.

## 검증

- 최종 CI: Flutter **587통과 / 브라우저 전용3건 건너뜀**, analysis0, 서버381통과, UI78, JS·Edge·5SQL 통과.
- 7언어 ×1,357개 사전 번역: 원문 키·숫자·변수 검증 통과.
- UI 번역: 8언어·변수 일치·번역 호출 키·태국어 잔여 영어·원문 fallback 회귀. 새8언어 보드 회귀는 매장 작성 제목/슬롯/ID 보존을 확인한다.
- 익명 Chrome390px에서 태국어 로그인/업무/운영 준비, 고정 보조 문구와 단계 라벨의 실제 표시를 확인했다. 실제 매장 데이터 수정이나 업무 완료는 하지 않았다. 브라우저 오류0; 기존 글꼴 preload 미사용 경고는 남아 있다.

## 실패와 복구

초기 Android 빌드는 다른 참조 프로젝트 properties의 상대 키 경로 때문에 실패했고, 해당 참조 키로 만든 업로드도 서명 불일치403으로 거절됐다. 임시 Play edit은 삭제됐으며 신규 키 생성/업로드 키 재설정을 하지 않았다. TAP Work의 기존 비공개 키를 찾아 기존 배포 인증서와 일치 확인 후 재빌드·제출했다.

초기 native17/18 및 Android16/17 산출물의 공개 Google define 누락을 비교 검사로 발견했다. 이전 Android15로 되돌리려는 임시 edit은 Google의 업그레이드 제한403으로 거절·삭제돼 트랙 변경이 없었다. iOS 임시17 심사 요청은 취소하고 내부 그룹에서 제거했다. 최종 iOS19/Android18에 기존 네 공개 설정을 복원했고, 기존 iOS의 미설정 Google 콜백을 알려진 공개 iOS client 값으로 구성했다. 실제 AOT 바이너리 포함·콜백 스킴·최종 제출 상태를 재검증했다. 서명·서버 비밀키·OAuth 공급자 콘솔 설정은 변경하지 않았다.

추가 보드 테스트의 최초8건은 담당 후보가 없는 fixture를 사용해 실패했고 가상 담당 후보를 명시해 해결했다. 테스트 전용 번들 Future 대기를 보완한 뒤 최종 전체 CI를 통과했다.

## 범위와 후속

실제 원어민/실기기/실계정 native 소셜 로그인 검수는 이번 작업에서 수행하지 않았다. 번역은 추가 사람 검토 대상이며 음식 안전 기준·수치·법규를 새로 승인한 것은 아니다. 운영 DB·공급처 주문·완료/급여 기록·실시간 유료 번역은 변경하지 않았다. 기존 미커밋 작업은 보존했고 `.local/localization-release`의 명시 파일만 배포했다.

비공개 증빙은 `.local/localization-deployment/`: AI 수정 전후/검토 CSV, CI 로그, 공개 hash 검사, native 서명·설정·자산 검증, iOS19/Android18 제출 및 실제 화면 캡처. credentials는 source/history에 포함하지 않는다.
