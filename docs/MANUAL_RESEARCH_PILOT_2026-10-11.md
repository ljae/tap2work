# Ego Lite 병렬 매뉴얼 조사 결과

작성: 2026-10-11 · 상태: **사장님 검토용 초안 · 독립 AI 쟁점 검토와 교정 반영**

## 실행 구성과 결과

| 역할 | 구성 | 산출물 |
|---|---|---|
| 전화 응대·예약·포장 | GPT-6 Luna · medium | 기존 6단계 유지, 예약/포장·문의/실제 접수 대사 분기 |
| 홀 오픈 | GPT-6 Luna · medium | 기존 5단계 유지, 통로·파손품 안내 보완 |
| 정기 시설·장비 관리 | GPT-6 Luna · medium | 기존 4단계 유지, 크루 외관 확인과 전문 정비 권한 구분 |
| 형식 정리 | GPT-6 Luna · low | 3개 주제·15단계 상세 문서와 앱용 JSON |
| 선택적 독립 검토 | GPT-6.1 Sol · medium | 안전·근거 범위 확인, 교정 6건 반영 |

모델/추론 단계는 코디네이터의 실제 `spawn_agent` 호출에 명시한 설정이다. 하위 에이전트가 내부 서비스 모델명이나 과금 정보를 직접 확인한 것은 아니다. 설정 근거와 하위 에이전트의 관측 한계를 실행 기록에 나눠 남겼다.

조사 세 건을 병렬로 수행했다. Ego Lite 공간 하나에 담당 페이지를 분리했고, 홀 조사가 끝난 페이지를 독립 검토 담당에게 넘겼다. 운영 데이터나 공개 매뉴얼 발행, 매장 등록은 수행하지 않았다. 기존 24개 제안 전체의 외부 조사가 아니라, 추천한 세 주제의 파일럿이다.

## 근거와 수정

- 실제 본문을 확인해 사용한 외부 자료는 **5건**이다: 전화1·홀2·설비2. 본문 미열람/메타데이터 확인 자료3건과 내부 기준4건은 외부 근거 수에서 제외했다. 출처별 링크와 적용 한계는 아래 매뉴얼에 표시했다.
- 전화 응대의 알레르기 정보 전달은 FSA의 영국 적용 범위를 명시했다. 인사·되읽기·예약 확정·회신·개인정보 기록 흐름은 매장 확인이 필요한 운영 제안으로 남겼다. 전화 영역은 목표 원문2~4개에 못 미쳐 서비스 대사 전체를 외부 모범실무로 검증했다고 주장하지 않는다.
- 홀 오픈은 통로를 막는 방식의 위험 통제와 파손품 취급 오해를 줄였다. 과거 학교급식실 자료와 미국 식당 자료를 한국 법적 의무로 옮기지 않았다.
- 설비는 자기 작업중지·대피와 장비 정지 조작을 구분했다. 표시만으로 작업 가능한 상태라고 판단하지 않도록 했으며 외관 이상 없음과 안전·성능 보증을 구분했다. 재가동 확인과 조작 권한도 명확히 했다.
- 장비 모델·제조사 설명서 본문·허용 작업·실제 주기·청소 제품은 미확인이다. 월요일 주간 점검은 기존 앱 제안이며 제조사 권고나 법정 주기로 확정하지 않았다.

## 자동 업무 연결 제안

| 매뉴얼 | 사용 방식 | 사장님 확인 후 연결 |
|---|---|---|
| 전화 응대 | 필요할 때 참고 | 통화마다 자동 할 일을 생성하지 않음 |
| 홀 오픈 | 매 영업일 루틴 | 기존 오픈 묶음에 연결; 정기 심층점검과 중복 생성하지 않음 |
| 정기 시설·장비 관리 | 정기 루틴 | 실제 모델·허용 작업·주기 확인 후 매장 일정에 맞춤 |

확정된 정책인 ‘휴무일 정기 업무는 다음 영업일’, ‘내일 변경은 이후 반복에도 적용’을 유지했다. 발주 후 재고 확인 기한은 시설 점검·입고로 미루지 않는다.

## 검증 및 파일

기존 sourceId/단계 ID·순서, 주장→출처 연결, JSON 구문, 제목100자/manual700자/tip400자 제한과 교정문 반영을 검사했다. 15단계 모두 통과했다. 설비 초안에서 빠졌던 `productionChanges:false` 메타데이터는 내용 변경 없이 보완한 뒤 재검증했다.

조사자는 브라우저 호출44회, 독립 검토는5회라고 집계했다. 이는 각 에이전트 실행 기록의 자체 집계이며 코디네이터의 공간 생성·종료 호출은 제외한다. 초기 검색 제안3개를 넘긴 사례와 접근 실패를 보존했다. 정확한 토큰/과금·모델별 속도·정확도 비교 실험은 수행하지 않았다.

# 매뉴얼 통합 초안

**상태: 검토 전 초안. Sol 안전 쟁점 검토와 사장님 현장 확인이 남아 있습니다. 사람 승인·운영 등록·배포가 완료되지 않았습니다.**

## 전화 응대·예약·포장 주문

**가정·사용:** 홀·주방이 있는 한국 소규모 한식 매장의 전화 응대 크루용 참고 매뉴얼. 매장별 가격·권한·기록 위치와 알레르기 안전 판정은 여기서 정하지 않는다. 전화가 왔을 때 참고하며 매 통화마다 자동 업무를 만들지 않는다.

### step-1 · 매장명과 함께 전화 받기

**언제:** 전화가 연결되면.
**수행:** 주변 소음과 손님 응대를 정리하고 “안녕하세요, [매장명]입니다. 무엇을 도와드릴까요?”라고 말한다. 문의가 예약·포장·기타 중 무엇인지 듣고, 바로 답할 수 없는 질문은 확인이 필요하다고 알린다.
**완료:** 문의 종류와 확인을 이어갈 담당이 분명하다.
**이상 대응:** 응대를 이어가기 어려우면 가능한 담당자를 확인한다. 실제 연결이나 회신이 정해지기 전에는 연결 완료나 콜백 확정을 말하지 않는다.
**근거:** P-01은 기존 순서를 초보자가 확인할 수 있게 다듬은 운영 제안이다. 독립 외부 근거는 없다.

### step-2 · 보류·연결에 먼저 동의 구하기

**언제:** 좌석·메뉴·준비 시간을 확인하려고 통화를 멈추거나 넘길 때.
**수행:** “확인할 내용이 있어 잠시 기다려 주실 수 있을까요?”라고 묻고 동의를 들은 뒤 보류한다. 오래 걸릴 것 같으면 통화로 돌아와 상황을 알리고, 전달할 때 고객 질문과 이미 확인한 답을 함께 말한다.
**완료:** 고객은 기다리는 이유를 알고 받는 담당자는 질문과 확인 내용을 이해한다.
**이상 대응:** 보류·전달 수단이 없거나 담당자를 찾지 못하면 통화로 돌아와 가능한 다음 방법을 안내한다. 정해지지 않은 회신 시각을 약속하지 않는다.
**근거:** P-02, 기존 보류·전달 흐름을 구체화한 운영 제안. 외부 서비스 표준으로 주장하지 않는다.

### step-3 · 예약 날짜·시간·인원 되읽기

**언제:** 예약표와 좌석 가능 여부를 확인한 뒤 확정 전.
**수행:** 날짜·요일·오전/오후·시간·인원·예약명을 묻고 지정 예약표에 기록한다. “10월 15일 목요일 저녁 7시, 네 분, [예약명] 맞으실까요?”처럼 되읽어 고객 확인을 받는다. 날짜 예시는 통화 당일 실제 요일을 확인해 바꿔 말하고 변경·취소는 매장 승인 문구를 사용한다.
**완료:** 고객 확인과 예약 기록의 날짜·시간·인원·예약명이 같고 좌석 가능 여부를 확인했다.
**이상 대응:** 만석·중복·불명확한 날짜·권한 밖 변경은 확정하지 않는다. 책임자에게 확인한 뒤 가능한 대안만 안내한다.
**근거:** P-03, 운영 제안. 예약표·확정 권한·변경 정책은 매장 확인이 필요하다.

### step-4 · 포장 메뉴·옵션·수령 시간 확인하기

**언제:** 포장 주문을 접수하고 주방 준비 가능 여부를 확인할 때.
**수행:** 메뉴명·수량·제공 옵션·제외 요청·포장 여부·희망 수령 시각을 하나씩 묻고 지정 주문 기록에 적는다. 알레르기 요청은 매장이 정한 담당자에게 전달하고, 조리 담당자가 내용을 받았고 이해했는지 확인한다. 주방에 품절·수량·실제 준비 가능 시각도 확인한다.
**완료:** 고객 확인과 주문 기록이 같고 주방이 준비 가능 여부 및 알레르기 요청 전달 내용을 확인했다. 전달 확인만으로 제공 안전을 보증하지 않는다.
**이상 대응:** 품절·시간 불확실·요청 해석 불명확은 확정하지 않는다. 승인된 알레르기 담당·정보·전달 절차가 없거나 조리 담당자 확인을 받지 못하면 접수를 확정하지 말고 책임자에게 넘긴다. 안전·제공 가능성은 추정하지 않는다.
**근거:** P-04는 주문 요소 확인 운영 제안. G-01/G-02는 영국 FSA 모범실무의 역할·정보 확인 및 조리 담당자 전달 제안을 제한적으로 반영한다. 한국 법규나 안전 보장이 아니다. U-01의 국내 페이지 본문은 읽지 못해 근거에서 제외했다.

### step-5 · 예약·포장 내용에 맞게 마지막으로 확인하기

**언제:** 예약 또는 포장 주문을 고객에게 최종 확인할 때.
**수행:** 예약은 날짜·시간·인원·예약명을 되읽고 포장 가격·수령 안내를 붙이지 않는다. 포장은 승인 가격 자료의 금액을 확인하고 수령 방법·시각을 안내한 뒤 “주문은 [메뉴·수량], 수령은 [확인 시각], 금액은 [확인 금액]입니다. 맞으실까요?”라고 되읽는다. 변경이 생기면 주방 접수와 전달을 확인한다.
**완료:** 예약 기록은 고객 확인과 일치한다. 포장은 고객 확인·주문 기록·주방 전달의 메뉴·수량·요청·수령 시각이 일치하고 금액을 승인 자료와 대조했다.
**이상 대응:** 가격 자료가 없거나 합계가 다르면 추정하지 말고 확인한다. 환불·취소·할인·결제 예외는 지정 권한자에게 넘긴다. 예약과 포장을 한 주문처럼 섞지 않는다.
**근거:** P-05, 현재 승인 자료를 사용하자는 운영 제안. 실제 가격·예외 권한은 정하지 않는다.

### step-6 · 통화 종료와 개인정보 정리하기

**언제:** 문의 답변 또는 예약·주문 접수를 확인한 뒤.
**수행:** 단순 문의는 “문의 감사합니다. 확인된 내용은 [답변]입니다.”라고 마무리한다. 실제 접수라면 고객이 확인한 [접수 내용]을 읽고 “말씀하신 내용으로 접수했어요.”라고 안내한다. 필요한 업무 내용만 지정 위치에 기록해 다음 담당자에게 연결하고 개인 기기·메신저로 옮기지 않는다.
**완료:** 단순 문의 답변과 실제 접수 상태가 구분되고 다음 담당자가 필요한 후속을 알 수 있다.
**이상 대응:** 부재 문의에는 확인된 담당·후속 방식만 기록한다. 회신은 승인 범위에서만 약속한다. 접근자와 보유·삭제 기간을 임의로 정하지 않는다.
**근거:** P-06, 내부 운영 제안이며 개인정보 법령이나 보유 기간의 근거가 아니다.

**사장님 확인:** 예약·포장 기록 위치와 열람 권한, 연락처·예약명 보유·삭제 기준, 좌석 확정·변경 권한, 주방 준비 시간·품절·주문 변경 경로, 승인 가격표와 결제/환불/할인 예외 권한, 알레르기 요청 담당·확인 자료·보류 기준, 보류·전달 수단과 승인된 후속 방법.

**자동 업무 분류:** `reference`; 반복 제안 없음. 통화마다 체크리스트를 만들지 않는다.

**미확인:** 직접 적용 가능한 한국 공식 전화·예약·포장 절차 원문은 확인되지 않았다. 매장별 기록·권한·개인정보 기준·알레르기 공정은 미확인이다.

**확인한 외부 자료:**
- [S-FSA-1 · Allergen information for non-prepacked foods: best practice](https://www.gov.uk/government/publications/allergen-information-for-non-prepacked-foods-best-practice/allergen-information-for-non-prepacked-foods-best-practice) — 본문 해당 구간을 읽음. 잉글랜드·북아일랜드·웨일스 범위의 해외 운영 참고이며 국내 법적 의무나 음식 안전을 확정하지 않는다.
- [S-FOOD-1 · 어린이급식관리지원센터 알레르기 유발 식품 표시 안내](https://www.foodsafetykorea.go.kr/portal/board/boardDetail.do?menu_no=4847&bbs_no=bbs039&ntctxt_no=1093585&menu_grp=MENU_NEW03) — **본문 미확인·참고 링크**. 제목·작성일만 보였고 본문이 이미지여서 주장 근거로 쓰지 않았다.

## 홀 오픈

**가정·사용:** 가정: 한국의 소규모 홀·주방 식당. 홀에 처음 배정된 크루가 매장 배치와 오픈 담당을 확인한 뒤 사용한다. 매 영업일 오픈 루틴이며 기존 daily/next_open을 유지한다. 자동 업무는 기존 오픈 업무에만 연결하고 정기 심층점검을 추가하지 않는다.

### step-1 · 입구·통로와 오늘 안내 확인

**언제:** 매 영업일, 홀 세팅 전.
**수행:** 문에서 좌석까지 지정된 손님 길을 천천히 살피며 물기·기름기·걸림 물건·통로 적재물을 확인한다. 안전하게 옮길 수 있는 가벼운 물건만 지정 위치로 옮기고, 영업시간·브레이크·마지막 주문을 우리매장 오늘 설정과 대조한다.
**완료:** 손님 출입·좌석 이동 길이 열려 있고, 오늘 안내가 매장 설정과 일치한다.
**이상 대응:** 위험이 남거나 문·바닥·누수에 이상이 있으면 안전한 거리에서 접근하지 않도록 안내하고 책임자에게 알린다. 통로·출입구·대피 경로를 막지 않고 매장 지정 통제 방식을 따른다. 통로를 확보할 수 없으면 오픈 완료로 표시하지 않는다. 무거운 적재물·누수·바닥/문 손상은 직접 처리하지 않는다.
**근거/범위:** 위험 인식은 안전보건공단 자료(S-HALL-01)와 미국 OSHA 식당 안내(S-HALL-03)에 한정해 참고했다. 두 출처는 한국의 법적 기준이나 매장 통제 절차를 정하지 않는다. 매장별 안내·동선은 C-HALL-02 확인 필요.

### step-2 · 테이블 번호별 좌석·집기 세팅

**언제:** 매 영업일, 예약 확인 뒤.
**수행:** 좌석 배치와 예약을 확인하고 테이블 번호 순서로 돈다. 매장 지정 제품·방법으로 닦고 예약 인원과 세팅표에 맞춰 의자·메뉴판·식기·수저를 놓는다. 통로를 비우고 흔들림·파손·눈에 보이는 오염을 살핀다.
**완료:** 예약·배치에 맞는 좌석에 매장 기준 집기가 준비되고 통로가 비어 있다.
**이상 대응:** 깨진 식기와 흔들리는 의자는 제공·사용하지 않는다. 파편을 맨손으로 만지지 말고 안전한 수거·이동 방법을 모르면 책임자에게 알린다. 세척 제품·방법도 먼저 확인한다. 불안정한 의자·테이블은 사용하지 않도록 알린다.
**근거/범위:** 청소 제품·방법과 세팅은 매장별 입력이며 조사 출처가 확정하지 않았다(C-HALL-02). 안전 관련 통로 위험 인식 범위는 C-HALL-01.

### step-3 · 셀프바 용기·도구·표시 준비

**언제:** 매 영업일, 셀프바를 운영하는 날만.
**수행:** 오늘 승인된 품목과 매장 준비·표시·보관 안내를 확인하고 지정 용기와 품목별 전용 도구로 준비한다. 보충분 위치와 교체 방법은 매장 안내를 따른다.
**완료:** 승인 품목·도구·표시가 서로 맞고 보충·보관 안내를 확인했다.
**이상 대응:** 이력·표시가 불명확하거나 오염이 의심되면 제공을 멈추고 분리해 책임자에게 확인한다. 새 음식과 섞거나 임의 재사용·폐기하지 않는다.
**근거/범위:** C-HALL-02는 매장 확인 필요, C-HALL-05는 이 조사에서 음식 안전 수치·법적 기준을 확립하지 못했다는 한계다. 별표 17 본문(S-HALL-02)은 확인되지 않았다.

### step-4 · 음용수·컵과 소모품 채우기

**언제:** 매 영업일, 손님 맞이 전.
**수행:** 컵의 파손·이물·물기를 살펴 지정 장소에 두고, 정수기 주변의 눈에 보이는 오염·누수·경고를 확인한다. 소모품은 매장 기준선까지 채운다.
**완료:** 제공할 컵과 소모품이 준비되고 물 사용 구역에 눈에 보이는 이상이 없다.
**이상 대응:** 물의 냄새·색·맛 이상, 누수, 경고가 있으면 사용을 멈추고 책임자에게 알린다. 분해·필터 교체와 대체 급수는 임의로 정하지 않는다.
**근거/범위:** 정수기 모델·청소/필터 주기는 확인되지 않았고 C-HALL-02 매장 확인 사항이다. C-HALL-05에 따라 안전 수치나 법적 기준을 추가하지 않았다.

### step-5 · 예약·품절·응대 변경 공유

**언제:** 매 영업일, 첫 손님 안내 전 및 변경 인계 시.
**수행:** 오늘 예약표와 좌석을 확인하고 주방 담당에게 품절·판매 재개 정보를 확인한다. 홀·주방이 같은 최신 안내를 확인하도록 매장 지정 기록을 갱신한다. 손님에게 확인된 정보만 짧게 말한다. 예: “확인하고 정확히 안내드릴게요.”
**완료:** 홀·주방이 같은 예약·판매 가능 정보를 확인하고 문의 전달 담당을 안다.
**이상 대응:** 예약·좌석·품절 정보가 다르면 확정 안내를 보류하고 담당자에게 연결한다. 가격·혜택·대기·취소 조건은 권한과 기준 확인 전 약속하지 않는다.
**근거/범위:** 일치 확인은 운영 제안 C-HALL-03, 권한 경계는 C-HALL-04이며 역할·기록 위치는 매장 확인이 필요하다.

**사장님 확인:** 손님/직원 동선과 통제·보고 방식, 테이블 제품·세팅표, 셀프바 공정·승인자, 정수기 모델·관리·대체 급수, 예약/품절 기록과 확정 권한.

**자동 업무 분류:** 기존 매 영업일 홀 오픈 routine 유지. 정기 심층 청소·설비 점검을 중복 생성하지 않음.

**미확인:** 법령 별표 상세, 실제 매장 동선·제품·셀프바 기준·정수기 모델·예약 권한.

## 정기 시설·장비 관리

**가정·사용:** 가정: 한국의 소규모 외식 매장. 장비별 모델·설명서와 담당자가 사장님에 의해 확인된 뒤 사용한다. 현재 월요일 주간은 기존 앱 기준선의 운영 제안이며 제조사 권고나 법정 주기로 검증되지 않았다. 휴무일은 다음 영업일로 이동(D-130). D-017 발주 후 재고 확인과 분리하며 설비 점검·입고가 기한을 미루지 않는다.

### step-1 · 이번 점검 대상·주기 확인

**언제:** 기존 주간 일정이 도래했을 때, 점검을 시작하기 전.
**수행:** 장비대장에서 설비명·위치·제조사/모델·최근 점검일·예정일·담당자를 확인한다. 해당 모델 설명서에서 크루에게 허용된 외관 확인과 청소 범위만 확인한다.
**완료:** 대상·담당·허용 범위·근거 문서·예정일이 확인된다.
**이상 대응:** 모델·설명서·주기가 없거나 전문 정비와 구분되지 않으면 추정하지 말고 분해·수리 없이 사장님 또는 정비 담당자에게 확인한다.
**근거/범위:** EQ-CL-03은 모델별 원문 확인 필요, EQ-CL-04는 월요일이 앱 제안임을 뜻한다. 제조사 첨부 PDF 본문은 읽지 않았다(EQ-SRC-03).

### step-2 · 영업 영향과 안전 상태 확인

**언제:** 외관 점검이나 설명서가 허용한 청소를 시작하기 전.
**수행:** 작업 구역·대체 장비·사용 재개 확인 책임자를 사장님과 정한다. 안전 정지나 에너지 격리가 필요한 작업은 해당 모델 절차에 따라 권한과 교육을 받은 사람이 맡는다. 크루는 담당자가 작업 가능한 상태와 허용 범위를 확인한 뒤 그 범위만 수행한다. 점검 중 표시나 인계만으로 정비를 시작하지 않는다.
**완료:** 담당자가 작업 가능한 상태와 크루 허용 범위를 확인했고 작업 구역·재개 확인 담당이 기록돼 있다.
**이상 대응:** 급박한 위험이면 자신의 작업을 멈추고 안전한 곳으로 대피한 뒤 지체 없이 관리감독자 또는 매장 지정 보고 담당자에게 알린다. 위험 장비에 접근해 정지·전원차단·가스 조작을 시도하지 않는다.
**근거/범위:** 산업안전보건법 제52조의 급박한 위험 관련 내용은 EQ-CL-02에만 연결된다. 실제 적용·현장 절차의 사장님 확인을 대신하지 않는다.

### step-3 · 누수·패킹·소음·필터 외관 점검

**언제:** 확인된 범위에서 장비 외관을 살필 때.
**수행:** 허용 범위의 눈에 보이는 상태만 확인하고, 해당 모델 설명서에 정상 기준이 있으면 비교한다. 장비명·위치·증상·발생 조건을 기록한다. 사진은 업무에 필요한 범위만 남긴다.
**완료:** 허용된 외관 확인 결과와 확인 필요·사용 보류 항목이 기록된다. 정상 기준이 없으면 확인 필요로 남기고, 눈에 보이는 이상이 없다는 것만으로 안전·성능을 보증하지 않는다.
**이상 대응:** 보호 덮개를 열거나 위험부에 손을 넣지 않는다. 계속 사용이 위험할 수 있으면 접근을 피하고 즉시 보고해 사용 보류 판단을 담당자에게 요청한다.
**근거/범위:** 식품안전나라 자료(EQ-SRC-01)는 시설 청결과 바닥 보수 안내 범위에 한정된다(EQ-CL-01). 모델별 점검 기준은 미확인(EQ-CL-03).

### step-4 · 조치·복구·다음 점검 인계

**언제:** 외관 확인 또는 설명서가 허용한 청소가 끝난 뒤.
**수행:** 확인된 모델 설명서와 매장 허용 범위 안의 청소만 한다. 교육·권한이 있는 지정 담당자가 해당 모델 절차로 사용 재개 조건을 확인하며 승인 전 크루가 임의 재가동하지 않는다. 미해결 건은 요청 번호·담당·기한·사용 보류 여부로 남긴다. 다음 날짜는 확인된 제조사 기준 또는 사장님이 정한 일정으로 기록한다.
**완료:** 수행 내용·재개 확인자/시각·미해결 조치·다음 예정이 구분되어 전달된다.
**이상 대응:** 체크 완료만으로 수리 완료나 안전 확인을 표시하지 않는다. 재개 기준이 불명확하면 사용 보류를 유지하고 담당자에게 넘긴다.
**근거/범위:** 모델별 확인은 EQ-CL-03, 주기 제안은 EQ-CL-04, 휴무일 이동은 확정 D-130(EQ-CL-05), 재고 기한 분리는 확정 D-017(EQ-CL-06)이다.

**사장님 확인:** 실제 설비 모델·설명서, 크루 허용 점검/청소 범위와 주기, 정비 경로, 사용 보류와 복구 확인 권한자.

**자동 업무 분류:** 기존 주간 routine은 기준선 제안으로 유지하되 주기 승인 전 확정으로 표현하지 않음. D-130 휴무일 이동과 D-017 재고 확인은 별도.
