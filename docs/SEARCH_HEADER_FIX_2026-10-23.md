# 검색 위치·상단 접힘 복귀 수정 — 2026-10-23

사용자 요청에 따라 매뉴얼·레시피 검색창과 검색 결과를 업무/매뉴얼에만 제공한다. 근무표/우리매장은 검색창 없이72px 브랜드 헤더를 사용한다. 상단 접기·공통 너비·검색 내용과 권한은 유지한다.

빠른 스크롤 후 상단이 다시 펼쳐지는 문제를 짧은 목록과 clamping/bouncing 두 물리 설정에서 재현했다. 기존 코드는 사용자 스크롤 상태가 남아 있는 동안의 관성/바운스 이동을 반대 방향 입력으로 처리하고, offset0이나 수동 입력 없는 음수 overscroll에서도 펼쳤다. 헤더가 접히면서 뷰포트가 커지면 목록이 경계를 넘거나 위치가 보정되어 이 문제가 발생할 수 있었다.

`AppScrollHeaderScope`는 직접 dragDetails와 휠 방향 통지 다음 한 번의 이동만 소비한다. 관성·바운스·크기 보정은 접힘을 뒤집지 않는다. 실제 위 방향 입력/당기기와 하단 메뉴 재선택으로 복귀하며 키보드/접근성/줄어든 모션 보호는 유지한다.
