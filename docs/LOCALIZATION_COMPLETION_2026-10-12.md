사용자 요청: 다른 언어로 바꾸었을 때 번역되지 않는 부분을 찾아 번역한다.

## 반영

- Flutter UI 59개 파일에서 고정 문구, 폼/편집 안내, 접근성 라벨, 날짜·수량을 포함하는 문장을 기존 AppStrings 경로로 연결했다. supplemental_messages.dart는 기존 번역을 재사용한 항목과 서버 업무 연결 진단을 포함해 1,764개 행을 한국어 및 7개 외국어로 제공한다.
- 지원 외국어: 영어, 베트남어, 간체 중국어, 일본어, 태국어, 네팔어, 인도네시아어.
- 운영 준비의 기본24매뉴얼110행동 및 첫 근무6개 안내에서 번들에 없던 원문을 보완했다. 공용109매뉴얼·기본 웰컴과 합쳐 각 외국어 번들은 정확한 원문 1,357개에 대응한다. 카탈로그 배포/등록과 번역 자산 보완은 별개다.
- 운영 준비의 목록·검색·검토 본문·내일 제목과 첫 근무 안내가 PreparedManualScope를 사용한다. 번역 제목으로 검색해도 검토/저장 대상 원문과 ID는 보존한다.
- enum/요일/업무 진단은 표시만 번역한다. 매장 작성 이름/수정 본문, 서버 상태 코드, 날짜·시간대, 수행·등록·사진·권한 및 저장 액션은 기존 계약을 따른다. 실시간 유료 번역은 비활성화 상태를 유지한다.
- UI 연결 검사 S23은 한국어 화면 문자 대신 기존 addTask 분기를 검사한다. 새로운 저장 효과를 만들지 않았다.

- 새 회귀 테스트10개: 8개 언어의 운영 준비/검토/미래 설정을 320px·1.5배 글자로 확인하고, 고정 문구의 변수·언어 누락 및 원문 fallback을 검사한다.

초기 점검에서 nullable 표시 변수/보조 함수의 context/const 문제를 수정했다. 번역 공급자가 숫자 표기를 바꾸거나 변수를 생략한 결과는 검사에서 거절했으며 예약 날짜/상시 가동/개수/사장님 표현 등을 보정했다. 추가 콘텐츠의 숫자 검사19건은 날짜 숫자를 그대로 유지하거나 원문에 없는 숫자 추가를 제거하여 해결했다. 처음 새 테스트8건은 화면 밖 목록을 누르거나 테스트의 번들 Future 완료를 기다리지 않아 실패했고, 실제 히트 영역까지 스크롤하고 기존 다국어 테스트와 같은 비동기 자산 대기 방식으로 고친 뒤 전체 재검증했다.

번역은 machine-assisted **ai-draft**다. 원어민 검수, 실브라우저/실기기 검수, 웹·네이티브 빌드/배포는 이번 작업에서 수행하지 않았다. 기존 미커밋 작업과 운영 데이터는 보존했다. 개인 계정·크루 데이터/비밀키를 번역 공급자에 보내지 않았으며 공개 원본과 고정 UI 문구만 번역했다.
