# 주요 결정사항 관리

기준 파일은 [`project-state.json`](./project-state.json)입니다. 웹 화면과 다음 개발 세션이 같은 파일을 사용합니다.

## 상태

- `confirmed`: 사용자와 확정한 방향
- `proposed`: 검토할 제안 또는 미정인 선택
- `deferred`: 이후 단계로 미룬 범위
- `superseded`: 후속 결정으로 대체된 내용

## 변경 방법

`npm run dev:console` 실행 후 http://localhost:3100 에서 결정 카드를 열고 내용·상태·변경 이유를 저장합니다. JSON 파일에 바로 기록되며 이전 값과 변경 후 값은 `history`에 남습니다. 웹을 새로 열어도 기록이 유지됩니다. 다른 창이 먼저 저장했다면 충돌을 알려 주고 다시 읽도록 합니다.

대화에서 결정한 사항을 직접 파일에 반영할 때도 최신 파일을 읽고 `revision`을 증가시키며 기존 이력을 보존합니다. 주요 개발 변경은 파일 경로와 실제 검증 결과를 함께 기록합니다. 파일을 수정했다고 앱 기능이 자동 구현되는 것은 아닙니다.

`product`는 제품 요약, `decisions`는 결정사항, `milestones`는 개발 단계, `history`는 개발·검증·결정 변경 이력입니다. `history`는 가장 오래된 항목부터 저장하며 웹에서는 최신순으로 보여 줍니다.

처음부터 Git 저장소는 아니었으므로 과거 이력은 대화와 작업 결과를 정리한 기록입니다. Git 커밋 이력이나 과거 시각을 만들어 내지 않습니다. 시각을 정확히 알지 못하는 이전 작업은 날짜만 기록했습니다.

개발자 웹은 로컬 컴퓨터에서 사용하는 도구입니다. 외부 공개·운영 환경 인증은 구성하지 않았습니다.
