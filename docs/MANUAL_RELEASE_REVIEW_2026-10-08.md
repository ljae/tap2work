# 공용 매뉴얼 변경 검토안 · 2026-10-08

**상태: 미발행. 공개 샘플에서 확인 가능하며 운영 stable은 기존 86개를 유지한다.**

원본 86개에 적용 범위·공정 메타데이터를 추가하고 5개 초안을 추가했다. 기존 bonejjim/break 본문은 기록/개인화 보존을 위해 남기되 신규 추천에서 제외한다. 운영 발행에는 정확한 초안 해시의 독립 검토가 필요하다.

신규 안전 관련 초안에는 공통 보관기간/온도 수치를 넣지 않았으며 매장 기준을 입력한 뒤 작업별로 활성화한다. 입력만으로 전문 검증이 완료됐다고 표시하지 않는다.

## 브레이크 · 영업 안내와 재개

`common/break-service` · universal · 권장 routine

- **중단·재개 시간 안내**: 우리매장 영업시간에 설정된 오늘의 브레이크 시작·종료 시각을 확인해 안내를 바꿔요. 특정 시각이나 주말 제외를 임의로 적용하지 않아요.
- **고객·인계 확인**: 진행 중인 응대와 전달할 사항을 담당 파트에 남겨요. 영업 브레이크와 크루 개인 휴게는 별개이므로 개인 휴게에 업무를 배정하지 않아요.
- **영업 재개 확인**: 설정된 재개 시각에 안내와 담당 파트의 준비 상태를 확인해요.

근거: [식약처 대량조리 음식 주의요령](https://www.mfds.go.kr/brd/m_827/view.do?seq=3607)

## 국물 배치 · 냉각과 보관

`process/broth-storage` · process · 권장 event

- **배치와 냉각 시작 확인**: 육수인지 해산물 등이 들어간 완성 국물인지 구분해요. 실제 제조량·용기·냉각 장비와 시작 시각을 기록해요. 큰 솥을 실온에 방치해 천천히 식히지 않아요.
- **냉각 기준 확인**: 매장에 검증된 용기 분할·냉각 방법을 사용하고 정해진 시점의 실제 시간·온도를 기록해요. 기준을 벗어나면 정상 완료하지 말고 사용을 보류한 뒤 책임자에게 알려요.
- **표시와 보관 확인**: 배치명·제조/냉각 시각·보관 위치와 매장에 확인된 사용기한을 표시해요. 다음 사용 때 이력을 확인해요. 짬뽕 국물에 통일된 보관 일수를 임의로 적용하지 않아요.

근거: [식약처 대량조리 음식 주의요령](https://www.mfds.go.kr/brd/m_827/view.do?seq=3607)

## 떡 · 개봉과 보관

- **제품·상태 확인**: 제품 표시의 보관방법과 소비기한을 확인해요. 실온 유통 밀봉 제품, 냉장·냉동 제품, 개봉·해동·불림·조리 상태를 구분해요.
