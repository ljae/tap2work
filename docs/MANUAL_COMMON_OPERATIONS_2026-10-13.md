## 화면과 번역

매뉴얼·레시피 읽기, 마켓과 본보기는 기존 AppPageRoute를 이용해 오른쪽에서 들어오는 가로 페이지로 연다. 편집 입력은 기존 초안 보호 시트를 사용한다. 실제 할 일의 폴더/TAP을 누르면 현재 task의 폴더나 TAP으로 이동한다. 디렉토리 상세도 같은 소속으로 복귀한다. 계정·매장·영업일이 달라진 응답으로 기존 화면을 이동하지 않으며 읽기와 이동은 완료 기록을 만들지 않는다. 동작 줄이기에서는 즉시 전환한다.

레시피 상세는 단계마다 등록 번역/준비 사전에서 제목·방법·팁을 읽는다. 설거지 본보기 폴더·TAP·상세20개 문자열을 실제 정의에서 번역 원문으로 수집한다. 영어·베트남어·중국어 간체·일본어·태국어·네팔어·인도네시아어는 각2047개 준비 문자열이다. 현재 원문1951개를 포함하며, 매장이 이전 버전을 유지하는 동안 필요한96개 과거 문자열도 남긴다. 숫자와 변수 보존을 검사한다. 원어민 검수는 미완료이고 ai-draft 상태를 유지한다.

기본 내용의 읽기는 유료 번역 API 호출 없이 준비된 번역을 사용한다. 매장별 수정 내용의 BYOK는 이번에 구현하지 않았다. API 키를 소스·운영 예제·개발 이력에 저장하지 않았다.
