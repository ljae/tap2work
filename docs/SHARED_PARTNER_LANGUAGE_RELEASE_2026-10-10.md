# 공통 파트너 화면·8언어·저비용 매뉴얼 번역

최신 사용자 결정은 D-119~123이다. 한국어/영어/베트남어/중국어 간체/일본어/태국어/네팔어/인도네시아어를 지원한다. 웹·iOS·Android 배포 요청은 유지한다. 실제 배포와 스토어 심사는 마지막 검증 기록으로 구분한다.

## 공통 화면과 권한

모든 파트너가 웰컴, 업무 목록, 행동별 설명·사진·체크, 매뉴얼 원본과 같은 진행 기록을 본다. 사장님을 특정 크루 신원으로 바꾸지 않는다. 완료한 사람은 실제 로그인 사용자다. 수정 권한, 담당 완료 권한, 비공개 급여·매출 범위는 기존 서버 검증을 유지한다.

웰컴은 첫 사용/사장님이 지정한 중요 변경에 별도로 열리고 업무로 바로 갈 수 있다. 각자 읽음 확인은 본인에게만 저장하며 업무 완료가 아니다. 헤더·우리매장에서 다시 볼 수 있다. 일반 수정은 모든 사용자에게 본문을 갱신하되 재확인을 강제하지 않는다.

현재 UI 번역 범위는 로그인·언어 선택, 공통 내비게이션, 웰컴/편집, 업무 카드·행동 슬라이드, 매뉴얼 조회/번역/검색, 주요 근무표·우리매장 조작이다. 기존 심화 재고·매출·관리 양식의 일부 문구는 한국어로 남아 있어 앱의 모든 문자열이 번역되었다고 보고하지 않는다. 매장 자체 파트명·장소명·메뉴명은 사용자 데이터이며 임의로 이름을 바꾸지 않는다.

## 비용을 낮추는 번역 운영

기존 공용 매뉴얼 109개와 기본 웰컴에서 중복을 제거한 990개 문자열을 7개 외국어로 미리 번역한다. 공개된 원문과 번역은 앱 자산으로 배포하여 조회할 때 외부 번역 API를 호출하지 않는다. 사전 번역은 AI가 작성한 초안이며 원어민 검수 완료로 표시하지 않는다. 안전 기준·수치·부정 표현을 보존하고 현장 문구는 매장 운영자가 수정할 수 있다.

번역 단위는 제목·행동 설명·팁·웰컴 본문이다. 원문 문자열이 일치할 때만 번역을 표시하고, 수정된 항목은 원문과 “번역 필요”를 표시한다. 다른 항목의 번역은 유지한다. 사장님/권한 있는 매니저가 해당 언어에서 번역 등록·수정을 열어 직접 입력하거나 JSON 양식을 복사해 작성 후 가져온다. 가져오기는 언어·원문·항목 ID를 검사한 뒤 기존 저장 revision으로 원자 저장한다. 기존 내용과 다른 번역을 자동 덮어쓰지 않는다. 번역 결과 보기와 원문 보기는 체크 상태를 바꾸지 않는다.

초기 운영 비용은 사전 번역 작성·검수와 앱에 포함되는 작은 텍스트 자산이다. 사용 횟수에 따른 번역 API 과금은 없다. 매장 수정본은 무료 직접 등록/가져오기를 우선하고, 향후 필요한 경우만 변경 항목·선택 언어를 모아 1회 번역하는 선택 기능을 검토한다. 그때도 원문 해시·언어별 재사용, 일별 문자 한도, 실행 전 예상 문자 수, 재시도 중복 방지, 사용자 명시 실행을 유지한다. 현재 Google Cloud의 기존 결제 계정은 비활성이라 API 키를 만들지 않았으며, 최신 사용자 선택에 따라 활성화 작업을 중단했다.

이전에 준비한 서비스 전용 번역 캐시/쿼터 SQL은 이미 적용되었지만 이번 운영 Edge는 유료 런타임 번역을 명시적으로 비활성화한다. 이 테이블 존재를 유료 번역 활성화로 보고하지 않는다.

## 크루 등록

새 크루 등록에서 국적(ISO 국가 코드)은 필수이고 안내 언어를 별도 선택한다. 249개 국적 목록은 검색해서 선택하며 국적으로 언어·권한·임금을 결정하지 않는다. 기존 미입력 국적은 추정하지 않는다. 국적은 사장님과 본인에게만 노출하고, 다른 파트너의 공통 업무 화면에 노출하지 않는다. 등록 시 언어는 초기 안내값이며 개인이 직접 선택한 언어가 우선이다.
