# 매뉴얼·공간 안내 적용 및 발행 검토 · 2026-10-09

사용자 요청으로 Flutter/API 구현을 진행했다. 운영 공용 콘텐츠는 **독립 검토 대기**다. 웹 코드 배포와 DB stable 발행은 별개이며 이 문서 작성 시 운영 stable은 기존 86개다.

## 적용한 사용자 흐름

처음 매장 등록에서 업종과 홀·포장·배달 방식을 선택하고 셀프바·테이블 화구 유무를 답한다. 외식업 공통과 업종 특화 추천을 구분해 보여주고, 선택한 매뉴얼을 매장에 가져온다. 업무 사용은 기존처럼 별도 활성화한다. 기존 매장은 우리매장 → 업종·기본 매뉴얼 및 매장 특성·공통 장소에서 설정한다.

셀프바·테이블 화구는 예/아니요/나중에 설정으로 구분한다. 미설정은 원본 절차를 유지한다. 조건이 바뀌어도 원본이나 매장 편집 내용은 지우지 않고 읽기/새 실행 구성에서 해당 절차만 제외한다. 미시작 해당 업무는 새 구성으로 생성하고 시작·완료한 실행은 보존한다. 영업시간·브레이크·파트는 기존 설정을 사용하며 새 입력 복사본을 만들지 않는다. 모든 기존 절차를 임의로 다시 쓰거나 모든 시간을 자동 재배정하는 기능은 아니다.

폐기물 배출·비품 보관 장소는 기존 zones ID를 연결하여 홀 마감·주방 마감·폐기물 매뉴얼에서 재사용한다. 실제 제목/본문/절차 편집은 코랄 연필+우리 매장 수정, 직접 만든 양식은 코랄 문서+직접 추가로 표시한다. 공통 조건·장소 변경만으로 수정 배지를 붙이지 않는다. 기존 자동 연결/개인화 분리 정책을 유지하며 새로운 원본 업데이트 정책을 확정하지 않는다.

## 공간 안내

공간·장비는 검색 가능한 장소 목록을 기본으로 한다. 이름·종류·선택적 층/건물·구역·찾는 방법·사진을 저장한다. 복잡한 모양을 격자에 맞추지 않아도 된다. 기존 배치도는 접힌 선택 영역으로 유지하고 층별로 편집한다. 등록한 장소를 같은 ID로 배치도에 놓을 수 있다. 기존 재고/준비품/실행 참조는 보존한다. 실제 도면 이미지 위 핀 편집은 이번 범위 밖이다.

사진은 JPG/PNG/WebP 최대350KB, 인라인 사진 전체1.5MB 문자 용량 한도를 적용한다. 대용량 원본/동영상 업로드 서비스는 아니다. 파일은 공개 샘플 생성에 섞지 않는다.
