# 휴대폰 웹 매뉴얼 접힘·로딩·공통 디자인 보완

사용자가 문제 환경을 **휴대폰 웹브라우저**로 확인했다. 기존 네 메뉴와 초록·코랄 색상, 한 열 매뉴얼, 공통 너비, 캘린더 정보 및 저장 계약을 유지한다. 이번 작업은 웹 개선이며 App Store 제출을 취소하거나 교체하지 않는다.

## 재현과 수정

- 짧은 매뉴얼 폴더 목록은 ListView의 기본 physics 때문에 터치 스크롤을 시작하지 못했다. 기존 긴 목록 테스트로는 확인되지 않았던 조건이다. directory·빈 레시피·검색 결과 스크롤에 AlwaysScrollableScrollPhysics를 적용해 화면에 다 들어가는 내용에서도 접기/복귀 입력을 받는다.
- 상단 도구 영역은 스크롤 본문 밖이어서 쓸어 올려도 접히지 않았다. AppScrollHeader의 세로 제스처를 공통 scope에 연결했다. 가로 도구 이동과 일반 버튼 탭은 기존 동작을 유지한다.
- 작은 휠/트랙패드 tick은 매번 ScrollStart에서 누적량이 초기화되어 임계값에 도달하지 못했다. 직접 PointerScrollEvent를 한 번 소비하고 240ms 이내 연속 입력만 누적한다.
- 손가락 방향은 dragDetails.globalPosition 차이로 판단해 접힘 애니메이션의 로컬 좌표 변화와 구분한다. 관성·바운스·프로그램 이동으로 재펼치지 않는다. 18px 접기/12px 복귀, 현재 메뉴 재선택, 접근성 탐색·키보드·동작 줄이기 보호를 유지한다.

초기 3개 회귀(짧은 매뉴얼, 상단 스와이프, 작은 휠)와 후속 빈 검색 결과는 **수정 전 실패 → 수정 후 통과**로 확인했다. 긴 목록/빠른 fling/뷰포트 확장/가로 스크롤/프로그램 jump/두 physics 설정 회귀도 유지한다. 폴더 편집·손잡이 이동·저장/취소 API는 바꾸지 않았다.

## 디자인

- AppColors의 forest 배경과 표면, mint/coral 강조, 밝은 본문·보조 텍스트로 공통 층위를 맞췄다. 기존 대비 자동 검사가 통과한다. 앱 전체 접근성 준수를 인증한 것은 아니다.
- 폴더는 둥근 배경·굵은 이름으로 TAP/내용과 구별하고 한 열 계층을 유지한다. 검색 표면/선과 하단 선택 캡슐·아이콘·라벨을 공통 토큰으로 정리했다.
- 웹 최초 화면과 Flutter 로딩 모두 브랜드·작은 물컵 모션·실제 단계 문구를 표시한다. 조회 중 2행 skeleton, 오류/12초 지연 재시도와 동작 줄이기 정지는 유지한다. 가짜 퍼센트·강제 로딩 시간은 없다.
- 좁은 높이/확대 글자는 스크롤하며 글자·재시도 버튼을 보존한다. 1240px 본문/좌우24px·Pretendard·48px 조작·네 목적지는 유지한다.

## 검증

- 전체 Flutter 652개 통과, 브라우저 전용 3개 skip. 이후 빈 검색 결과 physics 보완 후 최종 관련 33개 통과. 최종 source의 격리 분석 오류 0.
- 초기 관련 60개, 렌더 캡처 검사 9개/88장(320·390·1200·1600px × 글자1.0/1.5), 로딩 1개/9장(320·390·1200px, 짧은560px 높이/글자1.5) 통과. 로딩 재시도·오류·최신 시도 보호·동작 줄이기 기존 검사 유지.
- `npm run check`(UI 관계92개 포함), 매뉴얼 서버/웹 초기화 관련8개 통과. 최종 Flutter web release 및 새 정적 샘플 빌드 성공.
- Ego Lite 한 task space에서 로컬 390px/DPR2 Chromium 터치 입력으로 긴 매뉴얼·TAP 1개 짧은 폴더·상단 도구 스와이프의 접힘과1.2초 뒤 유지, 역방향/현재 메뉴 재선택 복귀를 확인했다. 공개 배포 검증은 후속 기록한다. 캡처·로그는 `.local/design-refresh-20261023/`.
- 중간 분석의 if 중괄호 lint1건은 수정 후 해소. 추가 검사에 존재하지 않는 검색 테스트 경로를 넣은 실행1건은 실제 header/language_controls 테스트로 수정해 최종33개 통과. 서버·앱 기능 실패로 보고하지 않는다.
- iPhone Safari 실기기, 네이티브 빌드·스토어 배포·실계정 저장 왕복은 이번 검증에 포함하지 않았다.
