# Ego Lite 미니멀 UI 검수 · 2026-10-09

검수 대상은 로컬 Flutter 릴리스 웹의 로그인, 업무, 매뉴얼, 근무표, 우리매장과 기존 설정 진입이다. 실제 사용자 인터뷰나 운영 계정의 업무 수행 검증은 아니다. Ego Lite task space 3의 같은 페이지에서 기본 모션으로 전후 화면을 비교하고, 작은 화면과 넓은 화면을 추가 확인했다. 캡처는 `.local/minimal-ui-review/`에 보관한다.

Ego Lite에서 파트 필터, 업무 내용 열기/목록 복귀, 매뉴얼 가로 도구 스크롤, 근무표 설정 진입, 우리매장 정보 시트 진입/닫기를 확인했다. 실제 저장이나 계정 로그인은 수행하지 않았다. 검토용 샘플만 사용했다.

최종 자동 검증: Flutter 전체387개, 정적 분석, 웹 빌드, UI57개 연결 검사와 관련 서버35개 검사가 통과했다. 최초 전체 검사에는4건 실패가 있었다. 2건은 이전 Task 버튼 문구를 찾던 모션 테스트, 2건은 새 데스크톱 테스트의 debug 플랫폼 복원 시점이었다. 모션 검증은 유지하며 내용 문구로 수정했고 플랫폼은 TargetPlatformVariant로 관리해 전체 재실행을 통과했다. 로그는 `.local/minimal-ui-review/flutter-tests-final.log`다. 최초 관련107개와 후속50/21/13개 실행은 전체387개에 별도로 합산하지 않는다.

Ego Lite 실제 DOM 측정: Google/Apple 로그인56px, 전체파트/주방/홀/관리 도구48px. 최종 모바일 캡처는 CSS 폭320/390 기준의 `*-320.png`, `*-390.png`, 데스크톱은1200 기준의 `*-1200.png`다. 모바일 캡처에서 Ego 기본 screenshot의 DPR 보정이 화면을 잘라내는 현상을 확인해 같은 Ego Page의 CDP 전체 캡처로 교체했다. Retina 출력 픽셀 폭과 CSS 화면 폭은 다르다.

전체 설정·모든 콘텐츠·실기기까지 전수 검수한 것은 아니다. 현재 확정한 단일 도구 행은 유지했으므로 작은 화면의 모든 동작이 동시에 보이지는 않는다. 외부 배포·네이티브 빌드·실제 OAuth 왕복·운영 데이터 변경은 수행하지 않았다.
