검토 02 / 7 · 매뉴얼과 실제 체크

어디까지 체크하면 좋을까요?

‘세척 구역 준비’ 한 업무를 체험해요.
짧은 행동을 보고, 필요할 때 방법을 깊게 열어요.

이번에 볼 것
  1. ‘준비물·방법·예시’를 열어보세요.
  2. 상세 설명을 보고 업무로 돌아오세요.
  3. 실제로 했다고 가정하고 완료를 체크해 보세요.

설명을 여는 행동은 완료로 기록되지 않아요.
신입에게 행동을 나눠 보여주는 정도만 비교해요.
