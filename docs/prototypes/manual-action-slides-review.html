검토 02 · 한 행동에 설명·사진·체크

보고, 하고, 체크하고.
다음 행동으로 넘겨요.

‘반납 식기 처리부터 건조까지’를 네 장으로 바꿨어요. 좌우로 넘기거나 아래 이전·다음 버튼을 눌러보세요.

각 장에 함께 보이는 것

핵심 행동 · 자세한 순서 · 놓을 곳과 사진
주의할 점 · 완료 기준 · 실제 수행 체크

넘기거나 사진을 보는 것만으로 완료되지 않아요. 수행 체크를 누르면 다음 행동으로 이동해요.

매장 사진 넣어보기

현재 보고 있는 행동에 사진을 넣어요.
사진은 자동 최적화한 뒤 이 브라우저 체험에 표시돼요.

촬영 후 자동으로 크기와 용량을 줄여요.
휴대폰에서는 후면 카메라 촬영을 요청해요.

체험 기록

사진이 없는 곳에는 위치 도식을 표시했어요. 식기 종류·배출 장소는 가상 예시이며 실제 매장 기준으로 바꿔요.
