# 휴대폰 작업 공간 리디자인 — 2026-10-22

사용자 요청에 따라 스크롤 시 상단 메뉴를 접고, 매뉴얼을 한 열로 구성하며 근무표의 표현을 개선했다. 기존 Flutter 앱의 로컬 소스와 웹 빌드에 반영했다. 운영 배포와 네이티브 빌드는 이번 작업에 포함하지 않았다.

## 구현

- 업무·매뉴얼·근무표의 세로 사용자 스크롤에 브랜드, 검색과 상단 도구가 함께 접힌다. 역방향 스크롤 또는 현재 하단 메뉴 재선택으로 복귀한다. 하단 네 목적지와 오류·저장 진행은 유지한다. 가로 이동과 프로그램 스크롤은 접힘을 유발하지 않으며 키보드·접근성 탐색에서는 자동 접기를 억제한다. 줄어든 모션 설정을 따른다.
- 매뉴얼은 최대 880px의 한 열 목록이다. ‘폴더 이동’ 시트에서 전체 또는 특정 폴더를 선택한다. 목록 연필로 해당 TAP/할일의 기존 편집기를 바로 연다. 읽기 페이지의 폴더 복귀, 권한, 드래그 이동, 저장 충돌 보호와 기존 기록을 유지한다. 폴더 선택 자체는 저장하지 않는다.
- 근무표는 날짜 이동과 오늘·주간/월간·설정을 분리하고 선택 날짜를 강조한다. 기존 영업시간·브레이크·휴무·추가 영업·배정·신청·출퇴근 정보와 동작을 보존한다. 월간 42칸의 좁은 날짜 칸에는 상태 아이콘과 범례·공휴일 목록을 사용하며 큰 글씨에서는 날짜 폭에 맞춰 내부 가로 스크롤을 허용한다. 24시간·영업시간/인원·크루 추가는 설정 메뉴에서 기존 동작으로 연결된다.
- API와 데이터 스키마 변경은 없다. 기존 녹색/코랄, 디자인 토큰과 네 목적지를 유지한다. 새 ‘폴더 이동’ 문구는 지원 8언어에 추가했다.
