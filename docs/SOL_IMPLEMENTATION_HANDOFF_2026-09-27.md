## 기술적으로 먼저 해소할 점

- blank 매장의 `zones: []`와 기존 체크리스트 필수 zone 검증을 일관되게 바꾼다.
- `saveChecklists`가 미시작 건을 archive하는 기존 동작과 새 설정의 ‘다음 생성부터 적용’을 저장 명령으로 구분한다.
- checklists validator/버전 비교/import/seed/주문 snapshot/공개 체험이 신규 settings를 보존해야 한다.
- 폼을 열었을 때의 revision이 polling 중 바뀌지 않게 한다.
- 새 프로필·채용 초안은 사장 전용을 기본 설계안으로 하고 역할별 응답에서 민감 필드를 제거한다.
- 순서 설정 OFF일 때 기존 실행 순서 변경을 유지하고, ON일 때 서버 재정렬 명령도 검사한다.
- 실제 route가 바뀌지 않는 곳에 Hero를 붙이지 않는다. 새 공통 motion은 현재 탐색 방식에 맞춘다.

방법론의 제안값을 구현 과정에서 조정했다면 실제 선택값과 이유를 문서·이력에 남긴다. 승인된 요구사항을 충족하는 합리적인 기술 조정 때문에 방법론 수립을 처음부터 반복하지 않는다.
