# 오케이포스(OKPOS) 샘플 매뉴얼 출처 · 2026-09-26

검색 가능한 Small TAP 예시는 사용자가 확인한 매장 POS인 오케이포스(OKPOS)를 기준으로 한다. 실제 화면과 버튼은 장비·버전에 따라 확인해야 한다. 이 앱은 POS에 연결되지 않으며 결제나 취소를 실행하지 않는다.

| 안내 | 공식 원문 | 샘플에 반영한 범위 |
| --- | --- | --- |
| 금액별 복합결제 | [OKPOS 복합결제](https://okpos.gitbook.io/okpos/undefined-3/undefined/payment/mixed_media) | 복합결제, 분할 금액 입력, 수단 선택, 반복, 마지막 잔액 및 영수증 내역 확인 |
| 상품별 더치페이 | [OKPOS 더치페이](https://okpos.gitbook.io/okpos/undefined-3/undefined/payment/per_person) | 결제 화면에서 더치페이, 이번 상품 선택 및 결제, 남은 상품 반복 |
| 취소 절차 | [OKPOS 영수증·취소 안내](https://okpos.gitbook.io/okpos/undefined-3/undefined/receipts) | 구체적인 취소 단계는 매장 장비와 공식 안내에서 확인하도록 안내 |

이전 토스 포스·페이히어 샘플 템플릿과 업무는 기존 저장 상태에서 보존하되 보드와 전역 검색에서는 보관 처리한다. 완료 기록과 편집된 매뉴얼은 삭제하지 않는다. 빈 매장에는 POS 샘플을 자동 생성하지 않는다.
