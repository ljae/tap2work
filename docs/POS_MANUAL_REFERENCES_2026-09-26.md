# POS 매뉴얼 출처 · 2026-09-26

검색 가능한 Small TAP 예시에 연결할 공개 제조사 자료다. 버튼 이름과 결제 방식은 제품·매장 유형·버전에 따라 다르다. 실제 매장이 쓰는 POS를 확인한 뒤 해당 매뉴얼만 업무에 사용해야 한다. 아래 내용은 결제를 실행하거나 결제 데이터를 가져오지 않는다.

| 제품과 범위 | 공식 사진 포함 원문 | 검색용 요약 |
| --- | --- | --- |
| 토스 포스, 후불형 매장 | [토스플레이스 분할 결제](https://tossplace.gitbook.io/guide/sector/postpaid-store/payment/split-payment) · [공식 제품 페이지의 가이드 연결](https://tossplace.com/product/pos) | 결제 화면의 분할 결제에서 금액·인원·메뉴 방식 중 하나를 선택하고 결제 수단을 정한다. 남은 금액을 확인하고 필요하면 반복한다. 분할 취소와 결제 수단 변경은 결제 내역에서 해당 건을 확인한다. |
| 페이히어 셀러, 지원되는 매장 유형 | [상품별·금액별 분할 결제](https://help-center.payhere.in/00e5bcff-326b-4b80-9e4f-892ea58607f9) | 주문 목록에서 상품을 선택해 따로 결제하거나, 결제 단계에서 금액 직접 입력 또는 더치페이 인원을 선택한다. 남은 상품·금액을 확인한다. |
| 페이히어 셀러 카드 결제 | [카드 결제와 환불](https://help-center.payhere.in/76da4d4a-0002-4fec-b877-f85603d547b2) | 환불은 결제 내역에서 대상 건을 선택해 확인하고 원 결제 수단으로 완료 여부를 확인한다. |
| 페이히어 GO 선불형 | [결제·환불](https://help-center.payhere.in/39203641-d648-8040-ac5c-f10bd65d3895) | GO 선불형의 금액 분할과 잔액 이어 결제는 일반 셀러 화면과 별도로 확인한다. |

페이히어 [라이트 결제 가이드](https://help-center.payhere.in/f5c152ec-aca1-4939-899e-8720e8006f36)는 라이트가 분할 결제를 지원하지 않는다고 명시한다. 따라서 위 분할 절차를 페이히어 전체 제품의 공통 기능으로 표시하지 않는다. 토스 후불형 가이드의 화면과 절차는 Aside CLI로 직접 확인했다. OKPOS 공식 문서에는 접근할 수 있었지만 해당 제품의 분할 결제 절차를 확인하지 못해 버튼 순서를 작성하지 않았다.

앱은 원문의 실제 화면 사진과 상세 절차로 이동하는 HTTPS 링크를 제공한다. 제조사 화면 이미지를 저장소에 복사하지 않는다. 매장 자체 레시피, 보관 위치, 주문 취소 및 추가 라이더 요청은 점주가 해당 매장의 승인된 절차와 사용 서비스에 맞춰 별도로 작성한다.
