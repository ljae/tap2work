# 매뉴얼 디렉토리 · 2026-09-27

- 사용자 명칭: TAP그룹 → TAP → Task. 매뉴얼은 Task에 연결한다.
- 좌측 트리: 그룹과 TAP 펼침/접힘, 선택 범위 표시, Task 선택 시 본문 표시. 760px 미만 본문 폭에서는 트리와 내용을 전환한다. 공통 상단 검색 위치를 유지한다.
- 검색: 디렉토리명·Task명·본문·연관어 검색. 선택 TAP그룹 또는 TAP 범위에서 결과를 좁히며 범위 칩을 지우면 전체 검색으로 돌아간다.
- 이동: 구조 편집 모드에서 같은 단계에 놓으면 그 앞 순서로, 상위 단계에 놓으면 그 안으로 이동한다. 위로/아래로 및 이동 위치 선택 메뉴도 제공한다. 마지막 Task를 다른 TAP으로 이동하는 것은 거절한다.
- 저장: `move_manual_node`는 사장님/매니저 권한과 드래그 시작 시 revision을 검사한다. 변경은 복사본 검증 후 원자적으로 반영한다. Task의 매뉴얼·링크·연관어·설정이 함께 이동하며 ID 충돌 시 이동한 Task에 새 고유 ID를 부여한다. 오늘 업무의 저장된 매뉴얼·완료 기록은 수정하지 않는다. 기존 보드의 템플릿 소속 표시 정책은 유지한다.
- 조회: 템플릿 정보가 숨겨지는 직원에게도 매뉴얼 검색 인덱스에 디렉토리 식별 정보를 제공한다. 오늘 발생한 주문/준비 Task 전용 매뉴얼은 조회용 항목으로 표시한다.
- 미리보기: 화면 내 복사본만 변경하며 POST를 보내지 않는다. 초기화 버튼으로 복원할 수 있다. 편집 화면을 벗어나면 미저장 체험 변경은 사라진다.

검증: Flutter analyze 통과, Flutter 105개 및 서버 69개 테스트 통과. Task 실제 드래그·본문 연결, 320px 탐색, 범위 검색, 권한과 revision 충돌, Task 설정 보존과 동일 ID 충돌 처리를 검증했다. 실제 Pretendard/아이콘 폰트로 1200px 좌우 분할과 390px 트리·본문·편집 화면을 캡처해 확인했다. 초기 간소화 테스트 fixture의 ID 누락을 처리한 뒤 전체 테스트를 통과했다. 네이티브 빌드·실기기 및 실제 로그인 계정의 저장 확인은 미수행이다.
