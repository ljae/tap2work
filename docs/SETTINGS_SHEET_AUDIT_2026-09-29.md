# 설정 시트 UI 점검 · 2026-09-29

Flutter `app/lib/ui`의 showAppSheet/showAppFormSheet/showModalBottomSheet, AppEditorScaffold/AppSheetPanel 및 설정용 대화상자 호출부를 정적 검토했다. 준비품 설정을 우선 수정하고 공통 시트의 정렬 문제를 고쳤다. 삭제/확인 등 짧은 대화상자는 유지한다. 배치도 본체는 편집 캔버스이며 입력 하위 시트만 공통 폼으로 통일했다.

## 발견 및 수정

- 준비품 추가/수정은 좁은 AlertDialog에 간격 없이 나열되던 입력을 기본 정보·수량 기준·업무 연결·메뉴별 사용량·준비 방법으로 나눴다. 실제 수량 보정도 같은 시트로 제공한다.
- 준비품 저장은 열 때의 actor/revision을 유지하고 성공 후에만 닫는다. 실패/충돌 시 초안과 오류를 유지한다. 컨트롤러는 시트 State가 소유한다. 닫기/뒤로가기에서 변경 버리기를 확인한다. 일부 메뉴가 응답에서 빠져도 기존 메뉴 연결을 지우지 않는다. 장소/폴더가 없는 빈 매장은 선행 설정 안내를 표시한다.
- AppEditorScaffold 본문을 위쪽 정렬했다. 짧은 폼이 세로 가운데로 내려가던 문제를 해결했다. 제목·폼·저장 영역은 공통 읽기 폭 688px(좌우 여백 제외 입력 폭 640px)으로 정렬한다.
- AppSheetActions는 취소/저장의 동일 폭과 최소 높이 56px를 사용하고 가용 폭/글자 배율에 따라 가로 또는 세로 배치한다. 글자는 축소하지 않는다.
- 영업시간 외에 파트 관리·직책 권한·크루 파트/시간대도 저장/오류를 하단에 고정했다. 주문 설정의 중복 제목을 제거했다.
- 크루 정보/시급·정산/우리매장 상세는 공통 제목 규칙을 사용한다. 메뉴·재료 입력과 근무 배정의 입력 정렬을 맞췄다.
- 배치 항목/매장 크기 입력은 AppSheetPanel로 통일하고 필드 간격을 20px로 맞췄다. 기존 초안/겹침/저장 검증을 유지한다.

`settings_sheet_audit_test.dart`는 22개 화면 유형을 320/390/1200px, 글자 1.5배, 키보드 280px 및 아래쪽 스크롤 상태로 검사한다. 프로필은 하위 탭도 전환한다. `settings_sheet_review.dart`는 실제 글꼴을 넣어 66개 캡처를 생성한다. 폰 22개 유형을 모아 시각 검토했고 준비품/공통 액션은 큰 이미지로 추가 확인했다. 캡처는 `.local/settings-sheet-review`이며 배포하지 않는다.

전체 Flutter 172개 테스트와 분석이 통과했다. 새 서버 API/DB 변경은 없다. 네이티브 빌드·실기기 키보드 및 모든 하위 옵션 조합의 수동 검증은 수행하지 않았다. 배포 후 실제 사이트에서는 저장하지 않고 시트 진입과 이름 편집창을 확인한다.
