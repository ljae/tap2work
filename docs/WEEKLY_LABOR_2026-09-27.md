# 주간 배정 · 인건비 · 상세 시트

## 사용자 확정

- 매뉴얼, 우리매장 운영 현황·재고와 발주·직원 상세를 바텀 시트로 제공한다.
- 직원 기본 배정 화면은 주간·직무별 필요 시간 슬롯 충족 여부다.
- 대한민국 기준 주휴수당 및 연장·야간·휴일근로 가산을 포함한다.
- 알림 범위는 앱 내 확인 목록이다. 휴대폰 푸시는 이번 범위에 포함하지 않는다.
- 기존 Pretendard·초록/코랄·회색 배경/흰 카드 UI 규칙을 유지한다.

## 구현

- 매뉴얼 트리/검색 선택과 업무 Task의 매뉴얼은 화면 크기와 무관하게 시트로 연다. 원래 트리·검색 범위를 유지한다.
- 우리매장 운영 현황·재고와 발주·직원·인건비·배치도 진입은 공통 시트다. 재고 담기 등 부모 상태 변경도 시트에 반영한다.
- 직원의 주간 표는 왼쪽 직무/시간축을 고정하고 월–일 열을 가로 스크롤한다. 30분 단위로 역할이 맞는 배정 인원을 필요 슬롯에 한 번씩만 대응한다. 교대 분할 근무는 합산하며 중복 필요 슬롯에 같은 사람을 두 번 세지 않는다. 휴가 근무는 제외한다.
- 슬롯마다 필요 요일을 선택할 수 있다. 요일 미지정 기존 슬롯은 종전처럼 매일 필요하다. 요일에서 제외해도 과거 근무 기록은 삭제하지 않는다. 필요 슬롯 밖 추가 근무는 날짜 상세에서 확인한다.
- 시급/지급 주기 및 종전 지급 기록은 별도 시트에서 관리한다. 월/주/일 선택은 시급제의 지급 주기이며 고정 월급 계약 계산기가 아니다.
- 사장님만 주간 인건비·개인별 세전 내역과 조건을 열람/저장한다. API는 다른 역할에 `labor`를 제공하지 않는다.
- 주간 조건은 직원+월요일 날짜로 저장하며 당시 기본 시급/통상시급을 포함한다. revision 충돌 시 초안을 유지하고 덮어쓰지 않는다.
- 실제 근태는 퇴근 완료 세션의 근로 구간만 계산한다. 휴게는 제외하고 초 단위 시간을 유지하며 겹치는 기록을 중복 합산하지 않는다. 금액 항목은 원 단위 반올림한다.
- 배정 예상은 휴게 차감 전 상한 성격의 예상이며 항상 해당 알림/라벨을 표시한다. 실제 지급은 근태 기준을 확인해야 한다.
- 주휴는 4주 평균 소정시간 15시간 이상 및 해당 주 요건 확인을 사용한다. 유급 주휴시간은 계약에 맞게 입력하며 주5일·40시간 통상근로자 기준 보조 계산 버튼을 제공한다. 입력한 주휴시간과 기본시급이 아닌 통상시급으로 계산한다.
- 5인 이상 표준 시급제 성인·고정 근로시간 조건에서 일8시간/주40시간 및 단시간 계약상 초과를 중복하지 않고 50% 가산한다. 야간(22–06시)은 50% 추가, 휴일근로는 8시간 이내 50%·초과 100%다. 휴일근로에 연장 가산을 중복하지 않고 야간 가산은 더한다. 상시5인 미만은 이 법정 가산을 적용하지 않되 주휴 요건은 별도로 판단한다.
- 휴일을 일요일로 추측하지 않는다. 적용되는 휴일근로 날짜, 주휴 외 유급휴일 지급시간, 상시 인원 구분을 사장님이 확인한다. 앱의 등록 직원 수를 법정 상시 인원으로 간주하지 않는다.
- 미확인 조건은 합계 `확인 필요`로 표시한다. 개근 미확인, 상시 인원, 휴일 확인, 최저시급 미달 설정, 주52시간/연장12시간 초과, 단시간 초과 동의, 부족한 휴게 기록, 미퇴근 등에 앱 내 확인 항목을 생성한다. 배정 변경/근태 변경 후 조회 시 다시 계산한다.

## 계산 범위와 남은 검증

현재 일반 성인·고정 시간·시급제의 **예상액**이다. 임금대장 확정/이체/세금·보험·퇴직금·연차수당·탄력/선택근로·미성년자·포괄임금·고정 월급·특례 계약은 포함하지 않는다. 이 범위 밖 계약은 미확인으로 남긴다. 직원 사장 직급은 자기 인건비 예상에서 제외한다.

주 경계 또는 휴일 경계를 넘는 연속근무는 귀속 판단이 필요하므로 합계를 보류한다. 통상시급은 계약/수당 구성을 확인해 입력한다. 법령 업데이트 자동 수집이나 공휴일 자동 판별을 구현하지 않았다. 기준 버전은 `KR-2026-09-27`, 2026년 최저시급은 10,320원이며 다른 연도는 별도 확인 알림을 제공한다. 입력 조건이 바뀌거나 특수 계약인 경우 담당자의 검토가 필요하다.

근무표의 월요일–일요일 주간 구분은 구현 기준이다. 사업장 계약의 기산일이 다르면 그 계약 기준으로 별도 확인해야 한다. 배정 충족률은 실제 출근·휴게를 보장하지 않는 계획 지표다. 기존 지급 기록 합계에는 법정 가산이 자동 합쳐지지 않으며 별도 라벨로 구분한다.
